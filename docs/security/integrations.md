# Security Integrations

Enhance Coolify with third-party platforms for protection, visibility, and control.

## Edge & DNS

- Cloudflare: WAF, rate limiting, Bot Management, origin certs, tunnels
- Tailscale/WireGuard: private networking for admin access

## Detection & Response

- CrowdSec or Fail2ban for IDPS
- SIEM (Logto, ELK/OpenSearch, Datadog) for centralized logs and alerts

## Secrets & Identity

- Secrets managers: 1Password, Vault, Doppler, cloud-native
- OAuth/SSO providers for centralized identity and MFA

## Backups & Storage

- S3-compatible storage for encrypted backups and long-term retention
